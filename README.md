# Password Reset Application - React Frontend

Modern React application built with Vite and Bootstrap 5 featuring a glassmorphism UI for user registration, login, forgot password, and reset password workflows.

## Pages
- `/` - Landing Page
- `/home` - User Dashboard (Protected)
- `/login` - Sign In Page
- `/register` - User Registration Page
- `/forgot-password` - Request Reset Email Page
- `/reset-password/:token` - Set New Password Page

## Setup & Running
```bash
npm install
npm run dev
```
Runs at `http://localhost:3000`.
